# android_releases_shieldtablet

Downloads of the unofficial LineageOS 18.1 (Android 11) build for the
NVIDIA SHIELD Tablet (shieldtablet). The builds are on the
[releases page](https://github.com/damnms/android_releases_shieldtablet/releases),
each with release notes, changelog and checksums.

## OTA updates

`shieldtablet.json` is the update list for the LineageOS Updater
(Settings → System → Updates), read through `lineage.updater.uri`. It
points to the zip of the latest GitHub release.

Sources: [local manifest](https://github.com/damnms/android_local_manifests_shieldtablet),
[device tree](https://github.com/damnms/android_device_nvidia_shieldtablet),
[kernel](https://github.com/damnms/android_kernel_nvidia_shield).
